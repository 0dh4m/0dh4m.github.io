How to Access from Outside Safely

Option A: Cloudflare Tunnel (Zero Trust Access)
When you want to access this dashboard from any browser in the world without opening any router ports:

TapoCam Stream & PTZ · System Architecture

Ultra-Low Latency WebRTC Video Gateway & ONVIF WSSE Security Protocol

1. ONVIF WS-Security Digest Generator

Generates standardized WSSE SOAP XML headers using cryptographically secure 16-byte random nonces and UTC ISO-8601 timestamps, combined with SHA-1 hashing to prevent replay attacks across local ONVIF PTZ endpoints. 

nonce = os.urandom(16)
created = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
sha1.update(nonce + created.encode() + password.encode())
digest = base64.b64encode(sha1.digest()).decode()

2. go2rtc WebRTC Low-Latency Pipeline

Bypasses high-latency HLS/RTMP transcoding by ingesting the RTSP stream directly and delivering H.264 video chunks via WebRTC DataChannels and MSE to achieve glass-to-glass latency under 180ms. 

streams:
  tapo_hd: rtsp://user:pass@192.168.1.50:554/stream1
  tapo_sd: rtsp://user:pass@192.168.1.50:554/stream2
api:
  listen: "127.0.0.1:1984"

3. Continuous PTZ Velocity Control Vectors

Translates browser joystick gestures into normalized continuous velocity vectors (\(v_x \in [-1.0, 1.0]\), \(v_y \in [-1.0, 1.0]\)) and issues ContinuousMove and Stop SOAP requests over ONVIF PTZ service port 2020.
