## 🚀 Local Development

Clone the repository and spin up a lightweight static HTTP server:

```bash
git clone https://github.com/0dh4m/portfolio.git
cd portfolio

# Using Python
python -m http.server 5500
```
Then visit `http://localhost:5500` in your web browser.
